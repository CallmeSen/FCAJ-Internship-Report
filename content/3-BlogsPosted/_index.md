This section presents the technical articles I shared with [AWS Study Group VN](https://www.facebook.com/groups/awsstudygroupfcj). The posts turn lessons from AWS learning and the Live-Auction project into practical topics that are relevant to cloud engineering work.

### [Blog 1 - Optimizing Amazon S3 Storage Costs](3.1-Blog1/)
An overview of Amazon S3 Storage Classes and Lifecycle Policies, with a practical retention strategy for application logs, user-uploaded files, and database backups.

### [Blog 2 - Lambda Scales Fast, but the Database Does Not](3.2-Blog2/)
An analysis of database connection pressure when moving the Live-Auction backend toward AWS Lambda, and how Amazon RDS Proxy can help protect Amazon RDS during traffic spikes.

### [Blog 3 - Building a Real-Time Auction Platform on AWS Serverless](3.3-Blog3/)
A project story about designing Live-Auction around Cognito, API Gateway, Lambda, DynamoDB, SQS FIFO, WebSocket broadcasting, Terraform, and AWS observability services.
