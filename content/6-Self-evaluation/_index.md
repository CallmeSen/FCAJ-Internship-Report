During my internship at Amazon Web Services Vietnam Company Limited through the First Cloud AI Journey program, I applied my academic knowledge to the development of the Live-Auction platform. My work covered system design documentation, React/Vite frontend workflows, Python serverless handlers, authentication, real-time bidding, infrastructure configuration, automated tests, and deployment checks. The repository history, including the CodeBuild setup, AWS infrastructure work, frontend authentication and auction workflows, and backend contract tests, reflects the gradual progression from analysis to implementation and validation.

The internship helped me understand that delivering a cloud application requires more than writing individual features. I had to consider interfaces between services, reproducible builds, security boundaries, testability, and the effect of a change on other team members. I also learned to communicate technical decisions through design documents, issue discussions, and concise status updates.

In terms of work ethic, I tried to take ownership of assigned tasks, keep changes reviewable, and verify behavior before considering a task complete. When an implementation was incomplete or an integration contract was unclear, I reviewed the surrounding code, reproduced the problem, and coordinated with the team instead of hiding the issue.

### Needs Improvement

- Improve effort estimation and task prioritization so that implementation, review, and documentation can be scheduled more consistently.
- Strengthen end-to-end testing across authentication, REST APIs, WebSocket bidding, and deployment environments. Unit and contract tests provide a good foundation, but broader integration coverage is still valuable.
- Communicate technical decisions more concisely in English, especially when presenting trade-offs, risks, and the expected impact of a change.
- Continue learning AWS observability, cost management, and security practices so that future solutions can be evaluated not only for functionality but also for operational readiness.
